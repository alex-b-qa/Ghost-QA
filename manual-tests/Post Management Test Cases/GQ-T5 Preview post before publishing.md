# Test: Preview post before publishing

## Objective
Verify that a user can preview a post before publishing.

## Precondition
- User is logged into Ghost Admin
- A draft post exists

## Steps
1. Open a draft post
2. Click the "Preview" button
3. Review the preview content
4. Click Close to exit preview

## Expected Results
- Draft post opens successfully
- Preview window opens
- Preview shows that post contents are as intended
- Preview window closes successfully
- User is returned to post editor

## Priority
Normal
