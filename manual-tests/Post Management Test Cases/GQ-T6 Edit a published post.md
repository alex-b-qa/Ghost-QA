# Test: Edit a published post

## Objective
Verify that a published post can be edited and updated.

## Precondition
- User is logged into Ghost Admin
- A published post exists

## Steps
1. Open an existing published post
2. Modify the post content by adding text
3. Click "Update"
4. Click "Posts"
5. ​Verify draft ​shows in posts list

## Expected Results
- Post opens successfully
- New text appears in the editable space
- Changes are saved successfully
- Header shows "Published"
- "Update" button is disabled
- Redirects to Posts list page
- Draft shows in posts list with status "Published"
- Draft shows time it was published and user that published it

## Priority
Normal
