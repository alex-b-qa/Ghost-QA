# Test: Delete a draft post from the editor

## Objective
Verify that a draft post can be deleted.

## Precondition
- User is logged into Ghost Admin
- A draft post exists

## Steps
1. Open a draft post
2. Open post settings in the header on the right
3. Scroll down and click "Delete Post"
4. Click "Delete"

## Expected Results
- ​Draft post opens
- Post settings menu opens
- Confirm delete option appears
- Post is deleted and no longer appears in Posts list
- Redirects to Posts list page

## Priority
Normal
