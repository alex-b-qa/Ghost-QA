# Test: Publish a draft post

## Objective
Verify that a draft post can be successfully published.

## Precondition
- User is logged into Ghost Admin
- A draft post exists

## Steps
1. Open an existing draft post
2. Click the "Publish" button
3. Click "Continue, final review"
4. Click "Publish post, right now"
5. Exit the confirmation window

## Expected Results
- Draft post is opened
- Publish confirmation screen appears
- Second confirmation screen appears
- Post status changes to "Published"
- Confirmation window appears
- Post appears in the post list with status "Published"

## Priority
High
