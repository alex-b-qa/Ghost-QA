# Test: Create a new draft post

## Objective
Verify that a user can create and save a post as a draft.

## Precondition
- User is logged into Ghost Admin

## Steps
1. In the navigation menu, click the "+" sign beside "Post"
2. Enter a post title
3. Enter post content
4. Click "Posts"

## Expected Results
- Transitions to editor page with a blank post loaded
- Post title displays in title field
- Post content displays in the body of the post
- Navigates back to list of posts
- Draft should appear in the list of Posts with status "Draft"

## Priority
High
