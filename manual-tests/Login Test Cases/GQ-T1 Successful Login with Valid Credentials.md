# Test: Successful Login with Valid Credentials

## Objective
Verify that a user can log in to Ghost Admin using valid credentials.

## Precondition
- Ghost Admin is accessible
- A valid user account exists
- User is on Ghost admin login page

## Steps
1. Enter a valid email address
2. Enter a valid password
3. Click the Sign in button

## Expected Results
- Email address is visible in email field
- Password shows in password field as masked characters
- User is logged in
- Admin dashboard page is displayed

## Priority
High
